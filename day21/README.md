# Recursion & Stack Practice

## Overview

Solved two LeetCode problems as part of the challenge:

* **Power of Four** — recursion
* **Min Stack** — stack

The goal was to practice recursion and stack-based problem solving while avoiding unnecessary built-in helper functions.

## Key Learnings

### Power of Four

* Used recursion to repeatedly divide the number by 4.
* Handled base cases such as `1` and invalid values.
* Learned the importance of checking whether the number is divisible by 4 before continuing recursion.

### Min Stack

* Used a stack to implement `push`, `pop`, `top`, and `getMin`.
* Stored the minimum value along with each element to retrieve the minimum in constant time.
* Practiced maintaining additional information inside a stack.

## Reflection

This challenge helped me understand how recursion depends on clear base cases and how a stack can store extra information to make operations more efficient. The main takeaway was to focus on the logic and data structure instead of relying on built-in shortcuts.
